# Portfolio Website — Abhi Chandra Yayi

A modern, responsive personal portfolio website built with **HTML**, **Tailwind CSS (CDN)**, and **vanilla JavaScript**.  
This site highlights my background, skills, certifications, experience, featured projects, and extracurriculars in a clean, recruiter-friendly format.

## Live Preview
abhiyayi04.github.io/Portfolio_Website/ 

---

## Features

- **Responsive layout** (mobile-first + desktop-friendly)
- **Smooth scrolling navigation** across sections
- **Animated section reveal** using `IntersectionObserver`
- **Extracurriculars section with smooth expand/collapse animation**
- **Clickable project cards** linked to GitHub repositories
- **Downloadable resume button**
- **Social links** (LinkedIn, GitHub, Email)

---

## Tech Stack

- **HTML5**
- **Tailwind CSS (via CDN)**
- **JavaScript (Vanilla)**
